# Tradfair Demo

A minimal demo project showcasing a simple static page for the Tradfair UI.

## Overview

This folder contains an example static site (HTML, CSS, JS) used for quick demos and prototypes.

## Files

- `index.html` — main HTML page
- `script.js` — demo JavaScript
- `style.css` — demo styles

## Usage

Open `index.html` in a browser to view the demo. For local development you can serve the folder with a static server, for example:

```
npx serve "./"
```

# Tradfair Demo

A small static demo project containing `index.html`, `script.js`, and `style.css`.

## Overview

- **Purpose:** Lightweight demo of a simple webpage (trade fair demo).
- **Contents:**
  - `index.html` — main HTML file
  - `script.js` — frontend JavaScript
  - `style.css` — styles

## Usage

Open `index.html` in your browser, or serve the folder with a simple HTTP server:

Windows / macOS / Linux (Python 3):

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

## Development

- Edit `index.html`, `script.js`, and `style.css` as needed.
- No build step required — this is a static demo.
